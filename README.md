# ALLINMenu 1.1.0
Paper 26.2 / Java 25

Главные изменения 1.1.0:
- GUI полностью защищён от кликов/перетаскивания предметов (InventoryClick + InventoryDrag + собственный InventoryHolder).
- Работы открывают подробную карточку профессии с живым прогрессом игрока, общим счётом, прогресс-баром и наградами уровней.
- Статистика читается напрямую из запущенных ALLIN-плагинов через reflection, с fallback на их players.yml.
- Кнопка «Фракции» сразу запускает /faction и открывает меню ALLINFactions.
- «Прокачка» заменена на «Топы».
- ТОП по 7 профессиям: лидер + общий накопленный счёт.
- /allinmenu tops start — старт 7-дневного цикла.
- Каждые 7 дней лидер каждой профессии получает $5000 через Vault. Если один игрок лидер нескольких профессий, он получает $5000 за каждую.
- /allinmenu tops stop — остановить цикл.
- /allinmenu tops status — посмотреть время до выплаты.
- Прокачка верстака теперь показывает три отдельных верстака I/II/III, шансы успеха, шанс/уровень зачарования и стоимость улучшения.
- Мастера обмена, EasyDonate и Telegram сохранены.

## Установка
Соберите JAR через GitHub Actions и замените старый ALLINMenu на новый.
Нужны Vault и работающий Vault-совместимый economy provider для еженедельных денежных выплат.

## Важно о счёте ТОПа
Так как счётчики профессий сбрасываются после повышения уровня, ALLINMenu считает общий накопленный счёт как:
сумма порогов уже пройденных уровней + текущий progress/souls.
На максимальном уровне текущий счётчик продолжает увеличивать ТОП.
